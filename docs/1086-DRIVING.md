# 高松210あ1086の運転と車両設定

Issue #8の更新には **scripts/UPGRADE_KOTODEN1086.cmd** を使う。既存マップでAT・完全MT・自動クラッチMTを選べる。[更新と運転の手順](1086-MT.md)


自動取り込みで作成したテストレベル `L_1086_Drive` を開く。F310 背面を **X** にして USB 接続し、エディター上部の **Play** 横のメニューで **Selected Viewport**、**Default Player Start** を選ぶ。**Play** を押し、ゲーム画面をクリックする。運転席から始まり、HUD の初期表示は **N、Park ON、Doors 0/0%**。このバスの UE 5.5.4 ビルド、実走行、クリック操作はクラウドで未検証。

## 発進・停車と操作

| 操作 | F310／キー | 運転席での操作・表示 |
| --- | --- | --- |
| レンジ | 上段の数字 **1 = D、2 = N、3 = R** | 左手側コンソールの黒い AT ノブをクリックすると N → D → R → N。停車して切り替える |
| 駐車ブレーキ | **Space** | コンソールの **P** をクリック。HUD の **Park ON/OFF** で確認 |
| アクセル・常用ブレーキ | **RT**／**A** | A は押している間に強まり、離すと弱まる。ペダルが動く |
| 操舵 | **左スティック X** | 右ハンドルと前輪が連動する |
| 前扉・中扉 | **F**／**M** | **F／M** ボタンでも開閉。HUD の **Doors** は前扉／中扉の実際の描画開度（%） |
| 前照灯・方向指示器 | **L**、**Q = 左、E = 右** | **L、<、>** が対応。再操作で消灯、反対方向を選ぶとそちらに切替 |
| 視点 | **C** | 運転席と追従視点を交替。運転席では **右スティック XY** で左右・上下を見回し、現物のスイッチにポインターを合わせて左クリック |

1. 停車したまま A を保持し、**1** で D を選ぶ。**Space** で駐車ブレーキを解除し、扉が両方とも 0% であることを確認する。
2. A を離し、RT を少し押す。HUD の車速・回転数・ギアを読み、速度計と回転計の針、車窓の移動と比較する。前方の試験場の端に達する前に減速する。
3. 低速で左スティックを左右に倒し、C で車外から前輪の操舵と車輪の回転、接地を確認する。Q／E で左右それぞれの点滅、L で前照灯、A で後部の制動灯を確認する。
4. RT を離して A を保持し、停止したら Space で駐車ブレーキを掛ける。F と M で個別に開閉し、車外から動きと HUD の開度を確認する。扉が開いている間・閉まり切るまでは駆動指令が遮断され常用ブレーキが掛かる。走行中に扉を操作しても開かないことを確認する。
5. 扉を閉め、A を保持したまま **3** を押し、HUD が **R** になったら駐車ブレーキを解除する。後方に余裕のある状態で A を離して RT を少し押し、後退を確認する。止めるときは RT を離して A を保持し、**2 → Space** で N・駐車状態へ戻す。
6. C で運転席に戻し、右スティックでハンドル左下の操作盤を向く。上表のキーで試した機能をクリックでも確認する。数字のギアは Chaos の現在段で、レンジ選択と実際の段切替は別々に表示される。

カメラとスイッチ用の Blueprint イベントは不要。HUD が P0-2 の入力表なら、開いたレベルの **World Settings → GameMode Override** が生成された `BP_KotodenDriveMode`、その **Default Pawn Class** が `BP_Kotoden1086` かを確認する。D にしても走らない場合は HUD の Park と両扉、接地、床の衝突、F310 背面の X を順に確認する。従来の MT・クラッチ試験は P0-4B の車両・レベルで行う。

## 車両の仮設定

6速ATは依頼者の車両指定。以下の数値は今回のモデルと平坦路用の初期調整値であり、実車の測定値は未確認。実車資料の照合状況は [実車資料と再現範囲](1086-REFERENCES.md) に記録した。

| 対象 | 初期設定 |
| --- | --- |
| 座標と寸法 | UE の cm 単位で +X が前方、+Y が車両右、+Z が上。前後車軸の中点の地面を原点とし、前軸 X=220、後軸 X=−220、車輪中心 Y=±94、Z=39 |
| 質量・重心 | 8,500 kg、重心 (−35, 0, 115) cm。ルートの箱形衝突と質量から Chaos が慣性を計算、テンソル倍率 (1,1,1) |
| ホイール・操舵 | インデックス順 FL、FR、RL、RR。半径39 cm、前後幅22／42 cm、前後輪質量70／120 kg。前輪最大43°、Ackermann。後輪駆動。後輪は左右の複輪それぞれを一つの接地点として扱う |
| サスペンション | 前／後の Chaos Wheel の Spring Rate 欄 2100／2700、減衰比 0.7、伸縮限界は上18／下16 cm |
| エンジン | アイドル650、上限2700 rpm。最大650 N·m。回転数 0／650／1400／2100／2700 rpm で相対トルク 0.45／0.65／1.00／0.83／0.55 |
| AT | Chaos の標準自動変速。前進比 3.49、1.86、1.41、1.00、0.75、0.65、後退比 5.03、最終減速比 5.57、効率 0.90。シフトアップ／ダウン 2200／1100 rpm、切替時間 0.4 秒 |
| 制動・インターロック | 1輪当たりの常用ブレーキ上限は前6800／後5500 N·m、後輪の駐車ブレーキは各10000 N·m。A の正規化指令は毎秒 +2／−3。レンジ・扉の操作は前後速度の絶対値 0.8 km/h 以下、扉の全行程は1.4秒、方向指示器は0.8秒周期 |
| 計器・表示 | 速度計 0–120 km/h、回転計 0–3000 rpm。車輪の回転角・舵角・ばね変位を Chaos から読み、ハンドル、針、扉、セレクター、スイッチ、ペダルを専用の描画メッシュで動かす。追加の Animation Blueprint は不要 |

車体・駆動は `BP_Kotoden1086 → Components → Vehicle Movement Component` で調整できる。タイヤ・ばねを変更する場合は `Kotoden1086FrontWheel` または `Kotoden1086RearWheel` の子 Blueprint を作り、**Wheel Setups → Wheel Class** の該当する2輪に割り当てる。乗車人数別の軸重、トルクコンバーターの流体・ロックアップ特性、エアブレーキの圧力応答、実車の最小回転半径・制動距離の再現は未検証。ミラーは鏡面材のモデルで、専用後方映像とワイパー作動は今後の項目。
